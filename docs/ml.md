# ML и LLM Стратегия

## 1. Распределение задач по методам

| Задача | Метод | Обоснование |
|---|---|---|
| **Очистка PII** | Regex + Natasha (NER) | Высокая скорость (< 10 мс), детерминированность. |
| **Классификация интентов** | CatBoost по TF-IDF / DistilBERT | Задержка < 30 мс, стабильная работа на CPU. |
| **Оценка риска** | Правила + Риск-классификатор | Гарантированный отлов финансовых и юридических тем. |
| **RAG (Поиск контекста)** | Hybrid Search (BM25 + BGE Embeddings) | Точное извлечение инструкций из базы знаний. |
| **Генерация ответа** | LLM (Qwen2.5-32B в локальном vLLM) | Высокая грамотность на русском языке при разумных затратах. |

---

## 2. Данные и разметка

* **Обучающая выборка**: 500 000 исторических тикетов с разметкой категории и корректного действия от операторов.
* **Active Learning**: Тикеты с неуверенным предсказанием ($0.50 < confidence < 0.75$) каждую неделю автоматически выгружаются на доразметку старшим операторам.

---

## 3. Пороги уверенности (Confidence Thresholds)

* **Confidence >= 0.80** и **Low Risk** -> Разрешен автоматический ответ.
* **Confidence 0.55 - 0.80** или **High Risk** -> Генерируется черновик для оператора (Suggest Mode).
* **Confidence < 0.55** -> Прямой перевод на оператора без вызова LLM.

---

## 4. Защита от галлюцинаций и Prompt Injection

1. **Strict Context Grounding**: В промпте прописано жесткое требование отвечать **только** на основе предоставленных фрагментов базы знаний.
2. **Input Sanitization**: Удаление системных команд вида `Ignore previous instructions`.
3. **NLI Verification**: Проверка семантического соответствия ответа исходному фрагменту инструкции.
